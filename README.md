# Synexus — 50 Days Web Development Challenge 🚀

## 📌 About the Challenge

This repository contains my work and progress throughout the **Synexus 50-Day Web Development Challenge**.

The challenge helped me build my web development skills step by step, starting with the fundamentals of HTML, CSS, and JavaScript and gradually progressing toward advanced concepts such as APIs, Web Components, state management, IndexedDB, WebSockets, Web Workers, and Service Workers.

The goal was to learn by building practical features and continuously improve the project throughout the 50 days.

---

## 🎯 Challenge Goals

* Strengthen HTML, CSS, and JavaScript fundamentals.
* Learn modern JavaScript concepts and ES6 modules.
* Build responsive and interactive web interfaces.
* Work with APIs and asynchronous JavaScript.
* Understand reusable Web Components.
* Implement client-side state management.
* Work with browser storage using IndexedDB.
* Learn SPA routing and application architecture.
* Explore WebSockets and Web Workers.
* Implement offline functionality using Service Workers.
* Build a complete Capstone project at the end of the challenge.

## 🗓️ Challenge Progress

The project was developed progressively across the 50-day challenge.

### Phase 1 — Web Fundamentals

Focused on the fundamentals of web development, including HTML, CSS, page structure, styling, layouts, and responsive design.

### Phase 2 — JavaScript & Interactivity

Introduced JavaScript functionality, DOM manipulation, events, forms, and interactive features.

### Phase 3 — Modern JavaScript & APIs

Focused on ES6+ JavaScript, modules, asynchronous programming, APIs, and dynamic data.

### Phase 4 — Advanced Web Development

Explored advanced browser and JavaScript concepts including Web Components, state management, browser storage, WebSockets, Web Workers, and related functionality.

### Phase 5 — Capstone

The final phase combined the knowledge gained throughout the challenge into a complete Capstone project.
